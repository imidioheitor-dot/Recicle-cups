# Irish Comeback — Blueprint Pack
### Unit 01 · Rev 1.0

Everything needed to build a bottle-to-filament line for under US$ 1,000.

```
docs/
  BUILD-TUTORIAL.md    Step-by-step build, first run, troubleshooting, NFC
  BOM.csv              Full bill of materials with vendors and prices
drawings/
  assembly-elevation.svg   Dimensioned side elevation, scale 1:8
  frame-panels.svg         Flat panels for laser cutting, 6 mm steel
  process-flow.svg         Material flow diagram, both lines
```

## Start here

1. Read `docs/BUILD-TUTORIAL.md` section 0 — safety. Not optional.
2. Order Line A from `docs/BOM.csv` ($342). Prove pultrusion works before
   spending the rest.
3. Cut the frame from `drawings/frame-panels.svg`.
